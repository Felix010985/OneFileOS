# OneFileOS – ОС написанная в одном файле
Это уникальнейшая операционная система написанная на Си всего в одном файле. Она работает в 32-битном защищённом режиме и не требует внешнего загрузчика.

## FAQ

### Как её собрать?
Надо выдать флаг x (eXecutable) на make.sh и запустить. Делается это вот так:
```bash
chmod +x make.sh
./make.sh
```

### Удобные функции расположены снизу или сверху? Какая структура файла?
Функции расположены сверху вниз, получается, что начальная инициализация и загрузка сверху, драйвера посередине, а в конце уже пользовательская часть ОС.

### Какие пакеты должны быть установлены в системе?
`llvm+clang`, `qemu-system`, `truncate` и `objdump`
